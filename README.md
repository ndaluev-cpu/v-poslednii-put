# v-poslednii-put

Статический сайт ритуальной службы «В последний путь…» с добавленной страницей поиска по названиям записей. Поиск работает полностью на стороне клиента, сохраняет запрос в URL и не требует бэкенда.

> **Демо:** [https://ваш-домен-на-beget.ru/search.html](https://ваш-домен-на-beget.ru/search.html)  
> (замените ссылку на реальный адрес после деплоя)

## Стек и версии

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6+)**
- **Без сборщика** (Webpack, Vite, Parcel не используются)
- **Без Node.js и npm** — проект не требует установки зависимостей
- Поддерживаемые браузеры: последние 2 версии **Chrome, Firefox, Safari, Edge** (включая мобильные версии)

Проект состоит из статических файлов и работает без серверной части.

Запуск локально
Поскольку поиск использует URLSearchParams и history.replaceState, страницу нужно открывать через локальный HTTP-сервер, а не через file://.

Вариант 1: Python (встроенный модуль)
Если установлен Python 3:

bash
python -m http.server 8000
Затем откройте в браузере: http://localhost:8000

Вариант 2: VS Code + Live Server
Установите расширение Live Server в VS Code.

Откройте папку проекта.

Нажмите правой кнопкой на index.html → Open with Live Server.

Вариант 3: Node.js (если установлен)
bash
npx serve .
Требования к ОС: Windows, macOS, Linux — любой, где можно запустить локальный HTTP-сервер.

Деплой на Beget
Проект не требует бэкенда — это статические HTML/CSS/JS-файлы. Деплой сводится к загрузке файлов на хостинг.

Шаги
Войдите в панель управления Beget.

Откройте раздел «Файловый менеджер» или подключитесь по FTP/SFTP.

Загрузите все файлы и папки проекта в корневую директорию сайта (обычно public_html/ или www/).

Убедитесь, что структура папок сохранена:

assets/ должна лежать рядом с HTML-файлами.

styles.css, script.js, expanded.js, search.js — в корне.

Откройте сайт в браузере и проверьте:

Главная страница загружается.

Изображения отображаются.

Иконка поиска в шапке ведёт на search.html.

Поиск работает (введите запрос, обновите страницу — запрос сохраняется).

Важно
Не меняйте структуру папок при загрузке — иначе изображения и стили не подключатся.

Поиск работает без бэкенда, поэтому не нужно настраивать PHP, базы данных или Node.js.

Если сайт открывается по HTTPS, history.replaceState и URLSearchParams работают корректно.

Как добавить новую запись в поиск
Поиск работает по массиву records в файле search.js. Чтобы добавить новую страницу в поиск:

Откройте search.js.

Найдите массив records в начале файла.

Добавьте новый объект в формате:

javascript
{ title: 'Название страницы', url: 'имя-файла.html' },
Например:

javascript
const records = [
  { title: 'Главная', url: 'index.html' },
  { title: 'О компании', url: 'about.html' },
  // ...
  { title: 'Новая страница', url: 'new-page.html' } // ← добавьте сюда
];
Сохраните файл и обновите страницу поиска.

Важно: поле title — это то, по чему идёт поиск. Поле url — ссылка, на которую перейдёт пользователь.

Известные ограничения
Поиск работает только по названиям записей (полю title в массиве records). По описаниям, текстам страниц или тегам поиск не идёт.

Поиск выполняется на стороне клиента. При очень большом количестве записей (тысячи) может потребоваться оптимизация (например, индексация или серверный поиск).

Записи в поиске не обновляются автоматически при добавлении новой страницы на сайт. Нужно вручную добавить объект в массив records в search.js.

Поиск не учитывает морфологию русского языка (например, «памятник» и «памятники» — разные запросы, хотя частично совпадут). Используется простое вхождение подстроки.

Замена ё на е выполняется, но другие особенности раскладки (например, латиница вместо кириллицы) не обрабатываются.
